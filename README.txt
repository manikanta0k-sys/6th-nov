BINOMO MULTI-ASSET CANDLE MONITOR V5.1 — DEMO RESEARCH ONLY

WHY V5 WAS SHOWING WAIT:
V5 intentionally gates future UP/DOWN on continuous, verified live screen capture. A single screenshot is only historical visual information and cannot certify next-candle direction. On iPhone Chrome, continuous capture of a different tab is generally unavailable/unreliable.

WHAT IS NEW IN V5.1:
- Historical LAST CLOSED 1m color: UP or DOWN from visually inferred candle.
- Historical LAST TWO COMPLETED 1m BARS (net pixel change), NOT guaranteed aligned to a 2m candle.
- Shows NO LIVE instead of unhelpful WAIT on next 1m/2m when input is only screenshot/offline.
- Live screen research still uses WAIT when data quality or timing is inadequate.
- Keeps 25-asset watchlist, 1m/2m clock windows, diagnostics, past learning journal, JSON/CSV export.
- Versioned scripts and new service worker cache to reduce stale Pages issues.

WHAT THESE DO NOT MEAN:
Green/red cards for PAST candles are not future predictions, and they cannot directly guide a Binomo order. Inferred chart pixels are not exact OHLC prices. No authenticated Binomo market feed or live trade execution.

HOW TO INSTALL (iPhone):
1) Download ZIP and extract in Files app.
2) Upload all six files to the ROOT of your GitHub Pages project on main branch: index.html, mobile-v51.js, learning-v51.js, manifest.webmanifest, icon.svg, service-worker.js.
3) After GitHub Pages deployment succeeds, visit https://manikanta0k-sys.github.io/5th/?v=51 only if your Pages repository is indeed '5th'.
4) In Binomo Demo pick Crypto IDX with 1m chart, take screenshot. In dashboard select Crypto IDX > Choose Screenshot. The app shows PAST 1m and PAST TWO-BAR color direction and live status NO LIVE.
5) For continuous live observations use a foreground desktop Chrome/Brave screen share if supported. iPhone Chrome may not allow cross-tab screen capture.

Back up the journal before deleting browser data or switching to another origin. DO NOT USE for real-money decisions.
